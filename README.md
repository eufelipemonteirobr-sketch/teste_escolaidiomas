# Escola de Idiomas

Sistema simples de gerenciamento de matrículas para uma escola de idiomas.

---

## 🚀 Tecnologias utilizadas

### Backend

* Laravel
* SQLite

### Frontend

* React
* Vite
* React Router
* Axios

---

## 📚 Funcionalidades

* Cadastro de cursos
* Cadastro de alunos
* Relacionamento entre alunos e cursos
* Dashboard com estatísticas

## ▶ Como executar o projeto

### Backend

Entrar na pasta backend:

```bash id="a1b2c3"
cd backend
```

Instalar dependências:

```bash id="d4e5f6"
composer install
```

Executar migrations:

```bash id="g7h8i9"
php artisan migrate
```

Rodar servidor Laravel:

```bash id="j1k2l3"
php artisan serve
```

---

### Frontend

Entrar na pasta frontend:

```bash id="m4n5o6"
cd frontend
```

Instalar dependências:

```bash id="p7q8r9"
npm install
```

Rodar projeto React:

```bash id="s1t2u3"
npm run dev
```
